PYTHON 3.13 COMPATIBILITY FIX
========================================

You're using Python 3.13, which is too new!
SQLAlchemy 2.0.23 doesn't support Python 3.13 yet.

SOLUTION 1: Downgrade to Python 3.11 or 3.12
---------------------------------------------
1. Download Python 3.11: https://www.python.org/downloads/
2. Install it
3. Run: py -3.11 -m venv venv
4. Run: .\INSTALL_NOW.bat

SOLUTION 2: Use Compatible Versions
------------------------------------
Run this in PowerShell:

    .\FIX_NOW.bat

This installs Python 3.13 compatible versions.
