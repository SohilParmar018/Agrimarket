AGRIMARKET - QUICK FIX FOR INSTALLATION
========================================

If you're seeing installation errors, follow these 3 simple steps:

STEP 1: Use Minimal Requirements
---------------------------------
pip install -r requirements-minimal.txt

STEP 2: Test Installation
--------------------------
python test_installation.py

STEP 3: Initialize & Run
-------------------------
python init_db.py
python run.py
